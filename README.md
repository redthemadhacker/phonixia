Phonixia
Educational Phonics Adventure Game
Free accessible phonics learning quest for kids. Exhibits 5 immersive magical realms, phonetic pronunciation challenges (BUH, EH, DAH, etc.), custom explorer creation with Kam & Celine guides, interactive realm mechanics (swimming in Sound Shallows, brick quarry in Builders Guild, minecart dashing, sky gliding), cross-device cloud account persistence with secure parental cybersecurity safeguards, and parent dashboard telemetry.

Dependencies
Linux Ubuntu 24.10, Github, VSCode, AI Studio Build
Javascript, TypeScript, Node.js, Express, React, Vite, Tailwind CSS, Web Crypto API

Help
Styling & Mobile Responsiveness: Fine-tuning touch ergonomics, dynamic viewport heights (100dvh), iOS Safari safe-area-inset padding, and responsive canvas scaling across various viewports to ensure seamless mobile play on Google Play, iOS App Store, laptop Safari, and tablet browsers without layout shifts or horizontal clipping.
Cybersecurity & Wi-Fi Protection: Enforced client and server-side password complexity parameters (uppercase, lowercase, number, special character, 8+ characters) with live requirement checklists. Implemented salted hashing, rate-limiting, and local LAN isolation headers to prevent unauthorized network probing on home Wi-Fi networks.
